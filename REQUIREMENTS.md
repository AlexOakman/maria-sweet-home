# Maria Sweet Home — требования к сайту

## Цель и рамки первой версии

Русскоязычный сайт-витрина кондитера Марии Дубинец в Краснодаре. Посетитель должен быстро понять, какие торты и десерты можно заказать, посмотреть реальные работы и написать Марии. Главные направления — свадебные и бенто-торты.

На первом этапе заказ обсуждается в мессенджере. На сайте нет корзины, формы заказа или онлайн-оплаты. Владелец обновляет контент через Git, поэтому административная панель в MVP не нужна.

## Заказ, доставка и стоимость

- Срочный заказ возможен от одного дня. Доступность даты уточняется при обращении.
- В Краснодаре доступны самовывоз и платная доставка. Стоимость доставки обсуждается отдельно и не входит в стоимость заказа.
- Предоплата — 50% на закупку ингредиентов.
- Для MVP стоимость торта обсуждается в переписке и зависит от декора. На сайте можно использовать формулировку «Стоимость зависит от оформления. Напишите, чтобы обсудить ваш заказ».
- Цены «от» допустимы после подтверждения актуальных сумм. Цифры из старого объявления пока не используются. Адрес и время самовывоза можно сообщать при согласовании заказа.

## Начинки

Для первой редакции использовать фотографии из папки «Материалы начинки» и названия из предыдущего объявления. Черновая подборка для бенто — красный бархат, «Сникерс» классический, клубничный пломбир, «Чёрный лес», «Молочная девочка», фисташковый пломбир с малиной и «Три шоколада». Перед публикацией сверить актуальность названий и соответствие фотографий. Для фото, которые пока не удалось сопоставить, использовать нейтральную подпись «Пример разреза». Точный состав указывать после подтверждения.

## Фото, видео и отзывы

- Использовать `Портрет.jpeg` на странице «О кондитере». Для первого экрана и основной галереи отобрать работы из папки «Хорошее качество последние».
- Свадебную и бенто-подборки можно дополнить материалами из папок «Коллаж Свадебный», «Коллаж бенто» и «Примеры с Авито». Для портфолио использовать собственные работы Марии, разрешённые к публикации.
- Для первого экрана выбрать короткий зацикленный фрагмент из папки «Видео». Предпочтительный формат — оптимизированное MP4 без аудиодорожки с неподвижной обложкой. При отключённых анимациях или недоступности видео показывать обложку. Текст и кнопка должны быть читаемыми на фоне ролика.
- Отобрать несколько скриншотов из папки «Отзывы». Кадрировать по одному отзыву, размыть имена и аватары клиентов в самих изображениях и дать возможность открыть скриншот крупнее.
- Визуальный стиль и отбор материалов можно определить при разработке. Географический акцент в текстах — Краснодар. Макеты должны работать на телефоне и компьютере.

## Поиск, аналитика и публикация

- Сделать страницы доступными для индексации. Для каждой страницы задать содержательные заголовок и описание, добавить подписи к фото и текстовые ссылки между разделами. Подготовить `sitemap.xml`, `robots.txt` и канонические URL для рабочего адреса.
- Приоритетные темы поиска — «свадебный торт на заказ в Краснодаре», «бенто-торт на заказ в Краснодаре» и «торты на заказ в Краснодаре». При запуске подтвердить сайт в Яндекс Вебмастере и Google Search Console и отправить карту сайта.
- Подключить статистику посещений. По возможности в MVP настроить отдельные события для кликов по MAX, телефону, Авито и Instagram. Сервис аналитики и доступ к счётчику определить при подключении.
- Опубликовать статический сайт на GitHub Pages в GitHub-аккаунте владельца. Первый запуск — на адресе GitHub Pages. Собственный домен планируется купить на год и подключить позже. После переключения проверить HTTPS и обновить адреса в карте сайта, канонических ссылках и панелях вебмастеров.
- Данные галереи, начинок, отзывов и контактов хранить в репозитории в удобном для редактирования виде. При передаче проекта дать короткую инструкцию по обновлению контента через Git.

## Проверки перед запуском

- Открыть страницы на мобильном и настольном экранах. Проверить навигацию, читаемость первого экрана, загрузку фото и замену видео обложкой.
- Проверить переход в MAX с телефона, кликабельность номера и работоспособность ссылок на Instagram и Авито.
- Сверить подписи к начинкам, права на публикацию работ и отображение отзывов. Подтвердить, нужны ли капкейки и трайфлы в ассортименте первой версии.
- Проверить сайт на опубликованном адресе GitHub Pages, доступность карты сайта для роботов и поступление тестовых посещений и кликов после настройки аналитики.
