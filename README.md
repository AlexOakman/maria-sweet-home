# Maria Sweet Home

Сайт-портфолио Марии Дубинец, кондитера из Краснодара. Состав первой версии описан в [требованиях](REQUIREMENTS.md).

## Локальный запуск

Нужен Node.js 24 или новее. Устанавливать пакеты не требуется.

```sh
npm run build
npm run check
npm run preview
```

Открой `http://127.0.0.1:4173/`. После правки контента снова запусти сборку и обнови страницу. Если нужно проверить сборку GitHub Pages локально, передай одинаковый `SITE_URL` при сборке, проверке и запуске.

```sh
export SITE_URL=https://alexoakman.github.io/maria-sweet-home/
npm run build
npm run check
npm run preview
```

Предпросмотр этой сборки доступен по адресу `http://127.0.0.1:4173/maria-sweet-home/`.

## Как обновлять контент

| Что меняется | Где редактировать |
| --- | --- |
| Контакты, портрет, условия заказа и первый экран | `content/site.json` |
| Работы и подписи к ним | `content/gallery.json` |
| Начинки и фотографии разрезов | `content/fillings.json` |
| Скриншоты отзывов | `content/reviews.json` |

Подготовленные медиа лежат в `public/assets/`. Добавляй изображения с короткими латинскими именами и понятным описанием в `alt`. Для мобильной версии можно положить рядом вариант шириной 480 пикселей с суффиксом `-480.webp`. Например, для `cake.webp` это `cake-480.webp`. Перед добавлением отзыва размой имя и аватар в самом изображении и сохрани изменённую копию.

Собери сайт, запусти проверку и отправь изменения в `main`. GitHub Actions пересоберёт опубликованную версию. Исходные папки с фото и видео, локальная сборка `dist/` и необработанные отзывы исключены из Git.

## Публикация из терминала

Локальный репозиторий связан с `AlexOakman/maria-sweet-home` через `origin`. Git отправляет все изменения из коммитов одной командой. Для первого входа с нового компьютера можно использовать GitHub CLI.

```sh
gh auth login --hostname github.com --git-protocol https --web
gh auth setup-git
```

Если ты меняешь файл публикации в `.github/workflows/`, авторизуй GitHub CLI с дополнительным правом `workflow`.

```sh
git add -A
git status --short
git commit -m "Update portfolio"
git push origin main
```

Для автоматической публикации в **Settings → Pages → Build and deployment → Source** выбери **GitHub Actions**. После отправки проверь запуск **Publish GitHub Pages** в разделе **Actions** и открой сайт. ## Поиск и статистика

- **Google Search Console.** Добавь URL с префиксом `https://alexoakman.github.io/maria-sweet-home/`. Выбери подтверждение метатегом HTML и запиши значение его атрибута `content` в переменную репозитория `GOOGLE_SITE_VERIFICATION`. После новой публикации подтверди права и отправь `sitemap.xml` из корня сайта.
- **Яндекс Метрика.** Создай счётчик для опубликованного URL. Запиши его номер в переменную репозитория `METRIKA_COUNTER_ID`, создай четыре цели типа «Целевое событие» с идентификаторами `contact_max`, `contact_phone`, `contact_instagram` и `contact_avito`. После публикации проверь посещение и переходы по четырём контактам. Для проверки событий можно открыть сайт с параметром `?_ym_debug=2`.
- Переменные добавляются в **Settings → Secrets and variables → Actions → Variables**. После изменения переменных повторно запусти публикацию. При пустых переменных сайт работает без кода подтверждения и счётчика.
- **Собственный домен.** После покупки подключи домен в **Settings → Pages** и настрой DNS и HTTPS. Рабочий адрес и префикс страниц берутся из настроек Pages при сборке. После переключения проверь канонические URL, `sitemap.xml` и корневой `robots.txt`. Добавь собственный домен в Яндекс Вебмастер и обнови настройки Google Search Console и Метрики.
